# URL2QR 기능 워크스루 (Walkthrough)

본 문서는 URL2QR 웹 사이트의 주요 기능과 사용 흐름을 단계별로 안내하는 워크스루 가이드입니다.

---

## 1. 사이트 실행 및 접속
프로젝트 폴더 내의 [`index.html`](file:///C:/Users/-/Desktop/프로젝트%2004/index.html) 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge) 등 최신 웹 브라우저에서 실행합니다.

---

## 2. 주요 기능 워크스루

### Step 1. 초기 화면 탐색
- **상단 좌측 로고**: 반투명 프로스티드 글래스 패널 안에 [`logo.png`](file:///C:/Users/-/Desktop/프로젝트%2004/img/logo.png)가 배치되어 있습니다.
- **마우스 반응형 앰비언트 배경**: 마우스 커서를 화면 곳곳으로 움직이면, 은은한 골든 라이트(Orbs)가 커서를 부드럽게 따라오며 화면의 그라데이션 색상이 실시간으로 변화합니다.
  - 마우스를 **화면 좌측**으로 이동: 상큼하고 화사한 레몬 골드 톤
  - 마우스를 **화면 우측**으로 이동: 따뜻하고 포근한 살구 피치 앰버 톤
- **중앙 입력창**: 화면 정중앙에 "빠르고 간편한 QR코드 생성" 문구와 함께 심플한 입력창이 표시됩니다.

### Step 2. URL 입력 및 QR코드 생성
1. 중앙 입력창에 변환하고자 하는 웹 주소를 입력합니다. (예: `naver.com`, `https://google.com`, 한글 검색 URL 등)
2. **생성하기** 버튼을 클릭하거나 키보드의 **Enter** 키를 누릅니다.
3. **트랜지션 효과**:
   - 메인 타이틀이 자연스럽게 사라지며 입력창이 **화면 하단**으로 부드럽게 미끄러져 내려갑니다.
   - 화면 **정중앙**에 고화질 QR코드 결과 카드가 스케일업되며 선명하게 나타납니다.

### Step 3. QR코드 클릭 및 JPG 다운로드
1. 화면 정중앙의 QR코드 위에 마우스를 올립니다.
   - 카드가 살짝 떠오르며 **"JPG 다운로드"** 오버레이 아이콘이 나타납니다.
2. **QR코드를 직접 클릭**합니다.
   - 800×800 해상도의 고화질 `.jpg` 파일이 즉시 다운로드됩니다.
   - 배경이 투명하지 않고 깔끔한 순백색(#FFFFFF)으로 처리되어 인쇄나 모바일 스캔 시 완벽하게 인식됩니다.
   - 화면 하단에 `📥 QR_naver_com.jpg 다운로드 완료!` 토스트 알림이 팝업됩니다.

### Step 4. 부가 편의 기능 활용
- **URL 복사 버튼**: 카드 하단의 "URL 복사" 버튼을 누르면 입력한 주소가 클립보드에 복사됩니다.
- **연속 생성**: 화면 하단에 고정된 입력창에서 언제든지 새 URL을 입력하고 Enter를 누르면, 정중앙의 QR코드가 즉시 새 내용으로 갱신됩니다.
- **처음으로 복귀**: 상단 좌측의 로고를 클릭하면 초기 상태로 부드럽게 복귀합니다.
