# URL2QR 작업 목록 (Task List)

본 문서는 URL2QR 웹 사이트 구축을 위해 수행된 모든 세부 작업 목록과 완료 상태를 기록한 문서입니다.

---

## 📌 작업 진행 상황 개요
- [x] **1. 프로젝트 환경 및 에셋 설정**
  - [x] `img/logo.png` 로고 이미지 배치 및 상단 좌측 헤더 마크업 구현
  - [x] 로고 클릭 시 처음 상태로 복귀하는 리셋 기능 연결
- [x] **2. 화면 중앙 UI/UX 입력 폼 구현**
  - [x] 미니멀한 검색창 스타일의 URL 입력창 마크업 및 스타일링
  - [x] 입력 내용 즉시 삭제 버튼(✕) 및 엔터키 지원
  - [x] 빈 입력 시 진동 애니메이션(Shake) 및 안내 토스트 메시지 구현
- [x] **3. 위치 전환 트랜지션 애니메이션**
  - [x] `body.has-qr` 클래스를 이용한 레이아웃 상태 전환 구조 설계
  - [x] 중앙 입력창이 화면 하단(바닥에서 24px)으로 매끄럽게 슬라이드 다운되는 애니메이션 구현
  - [x] 타이틀 영역의 자연스러운 페이드아웃 및 축소 처리
  - [x] 화면 정중앙 QR코드 카드의 팝인(Pop-in) 스케일업 애니메이션 구현
- [x] **4. QR코드 생성 엔진 고도화 및 오류 수정**
  - [x] 구형 `qrcode.js` 라이브러리의 한글 UTF-8 바이트 파싱 결함(`bad rs block` 오류) 분석
  - [x] 한글/영문/특수문자/긴 URL을 100% 무결점 지원하는 `qrcode-generator` 엔진으로 교체
  - [x] 고해상도(Retina 디스플레이 대응) HTML5 Canvas 직접 렌더링 로직 구현
  - [x] 폼 중복 서브밋(Click + Submit) 이벤트 충돌 방지 단일화
- [x] **5. 고화질 JPG 다운로드 기능**
  - [x] QR코드 클릭 시 800×800 해상도 오프스크린 캔버스 전사 처리
  - [x] JPEG 투명도 결함 방지를 위한 `#FFFFFF` 순백색 배경 및 여백(Quiet Zone) 처리
  - [x] 입력된 URL의 도메인을 추출하여 의미 있는 파일명(예: `QR_naver_com.jpg`) 자동 생성
  - [x] QR코드 마우스 호버 시 "JPG 다운로드" 오버레이 및 안내 뱃지 노출
- [x] **6. 로고 연계 밝은 톤 앤 매너 & 마우스 인터랙티브 그라데이션**
  - [x] 로고의 앰버 골드(`#FFC000`)에 최적화된 밝고 따뜻한 프로스티드 글래스(Glassmorphism) 테마 구축
  - [x] 마우스 커서 위치 실시간 추적 및 Lerp(감속 보간율 0.08) 물리 엔진 적용
  - [x] 커서 좌표에 따른 실시간 HSL 색조 변조 (좌: 레몬 골드 54° ~ 우: 살구 피치 38°)
  - [x] 3중 앰비언트 Glow Orbs 광원 레이어링
- [x] **7. 반응형 웹 및 접근성 최적화**
  - [x] 뷰포트 높이 720px 이하 환경(노트북 등) 레이아웃 겹침 방지 미디어 쿼리 추가
  - [x] 키보드 접근성(Enter/Space 키로 QR 다운로드 실행 가능) 적용
  - [x] 모바일/태블릿 터치 화면(`touchmove`) 인터랙션 지원
