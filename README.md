## 🚀 3. 핵심 기능 요약

### ① 통합 네비게이션 시스템
- **'QR코드' 버튼**: 클릭 시 `url2qr/index.html`로 즉시 연결.
- **'URL단축' 버튼**: 클릭 시 `urlShort/index.html`로 즉시 연결.
- 메인 포털과 두 하위 서비스의 상단 헤더에 상호 전환 탭이 탑재되어 어느 화면에서나 자유롭게 이동 가능.

### ② QR코드 생성 (`url2qr`)
- 한글, 특수문자, 초장문 URL을 오류 없이 지원하는 `qrcode-generator` 엔진 탑재.
- 고해상도(800×800) 오프스크린 캔버스 전사를 통한 **JPG 원클릭 다운로드**.
- 생성된 QR코드를 화면 정중앙에 배치하는 부드러운 글래스모피즘 트랜지션 애니메이션.

### ③ URL 단축 (`urlShort`)
- **실시간 버튼 활성화 제어**: URL 입력 필드가 비어 있으면 '단축하기' 버튼이 비활성화(`disabled`)되며, 텍스트가 입력되면 자동으로 활성화.
- **OpenAPI 기반 실시간 단축**: 브라우저 CORS를 지원하는 OpenAPI(`is.gd`, `v.gd`, `TinyURL`) 3중 Fallback 연동.
- **읽기 전용 출력 상자**: 단축 완료된 결과를 안전하게 확인하고 선택할 수 있는 읽기 전용(`readonly`) 출력창.
- **원클릭 클립보드 복사 & 알림**: '복사' 버튼 클릭 시 클립보드에 자동 복사되고 `복사하였습니다` 토스트 알림창 노출.
- **QR 연계 기능**: 단축된 URL을 한 번의 클릭으로 `url2qr`로 전달하여 즉시 QR코드로 생성 가능.
- **단축 히스토리**: 최근 단축한 링크를 로컬 스토리지에 자동 저장하여 재사용 지원.
